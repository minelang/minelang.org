> Sections are **visual organizers** - no semantic meaning, ignored by the compiler, used by the LSP for outline navigation.

---
<br>

- ## Level 1

    ```mine
    ╔════════════════════════════════════════ TYPE ════════════════════════════════════════╗

        def MyStruct = struct {..}

    ╚══════════════════════════════════════════════════════════════════════════════════════╝



    ╔════════════════════════════════════════ CORE ════════════════════════════════════════╗

        pub fn main(){..}

    ╚══════════════════════════════════════════════════════════════════════════════════════╝
    ```

    > Three `\n` between `level-1` sections

---
<br>

- ## Level 2

    > Must be inside `level-1` section.

    ```mine
    ╔════════════════════════════════════════ TYPE ════════════════════════════════════════╗

        def MyStruct = struct {

            ┌────────────────────────────── INIT ──────────────────────────────┐

                init(){..}

            └──────────────────────────────────────────────────────────────────┘


            ┌────────────────────────────── HELP ──────────────────────────────┐

                pub fn help(){..}

            └──────────────────────────────────────────────────────────────────┘

        }

    ╚══════════════════════════════════════════════════════════════════════════════════════╝
    ```


    > Two `\n` between `level-2` sections
