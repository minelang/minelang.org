Write a simple program that prints "Hello World!" to the standard output stream 🚀

---

1. Create a file called `main.mine` with the following code:

    ```mine
    fn main() {
        @printn("Hello World!")
    }
    ```

2. Use `mine run main.mine` command to build and run it.

    ```bash
    # Output
    Hello World!
    ```
