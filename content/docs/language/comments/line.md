---
title: Line Comment
description: A comment that spans a single line.
icon: comment
weight: 113
---

> Starts with `//` and continues to the end of the line. Used for inline notes or temporarily disabling code.

---

- ### Syntax

    ```mine
    // comment
    ```

    ---

- ### Examples

    ```mine
    // This is a standalone single-line comment
    var score = 100;
    ```

    ```mine
    var health = 50; // This is an inline comment explaining health
    ```

    ```mine
    // This comment spans
    // across multiple lines
    // in your code
    const total = score + health;
    ```
