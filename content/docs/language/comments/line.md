> Line comments are used to annotate specific parts of code without affecting execution.
>
> They are typically used for explanations, clarifications, or temporary notes inside code.
---

- ### Syntax

    ```mine
    // comment
    ```

    ---

- ### Examples

    ```mine
    // This is a standalone single-line comment
    var score = 100;
    ```

    ```mine
    var health = 50; // This is an inline comment explaining health
    ```

    ```mine
    // This comment spans
    // across multiple lines
    // in your code
    let total = score + health;
    ```
